# OpsHR

Human Resource Management System within the MYOPS ecosystem.

## Release policy

- Development and UAT first; no public production launch without explicit approval.
- MYOPS provides central authentication and subscription entitlements.
- No standalone OpsHR password login.
- Never use real employee data in development fixtures.

## Planned Phase 1

Employee directory, departments, leave requests, attendance overview, and secure MYOPS integration.
